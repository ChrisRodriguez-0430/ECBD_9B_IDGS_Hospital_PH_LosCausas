# DataBases – ORATIO

En este apartado se encontrarán los archivos, imágenes, diagramas, scripts, queries, triggers y USPs del proyecto **ORATIO**.

## Estructura de Archivos

```
DataBases
├── NoSQL
│   ├── Backups        ← Respaldos de la base de datos NoSQL
│   ├── DD             ← Diccionario de Datos
│   └── Schemas        ← Esquemas y modelos de colecciones
└── SQL
    ├── Backups        ← Respaldos de la base de datos SQL
    ├── DD             ← Diccionario de Datos
    ├── ERD            ← Diagrama Entidad-Relación
    └── RM             ← Modelo Relacional
```
