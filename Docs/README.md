# Docs – ORATIO

En este apartado se encuentra toda la documentación del proyecto **ORATIO**.

## Estructura de Archivos

```
Docs
├── BRs             ← Business Requirements (Requerimientos de Negocio)
├── FRs             ← Functional Requirements (Requerimientos Funcionales)
├── GUIs
│   ├── WearableApp ← Diseños de interfaz para la app wearable
│   └── WebApp      ← Diseños de interfaz para la aplicación web
├── NFRs            ← Non-Functional Requirements (Requerimientos No Funcionales)
├── UHs             ← User Histories (Historias de Usuario)
└── URs             ← Use Cases / Use Requirements
```
