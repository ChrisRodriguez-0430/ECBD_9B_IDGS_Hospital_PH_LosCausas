# Docs - Documentación General
![Docs](https://img.shields.io/badge/DOCS-DOCUMENTACI%C3%93N-007ec6?style=flat-square)    ![Markdown](https://img.shields.io/badge/Markdown-%23000000.svg?style=for-the-badge&logo=markdown&logoColor=white)

En este apartado se concentra toda la documentación oficial del Sistema de Gestión Farmacéutica Hospitalaria, desarrollado para el Departamento de Farmacia de un hospital de tercer nivel. Abarca desde los requerimientos de negocio y usuario hasta los prototipos de interfaces, proporcionando una visión completa del alcance, funcionalidad y diseño del sistema para la administración centralizada de medicamentos, inventario, compras y dispensación.

## Estructura de Archivos

```
Docs
├── BRs             ← Business Requirements (Requerimientos de Negocio)
├── FRs             ← Functional Requirements (Requerimientos Funcionales)
├── GUIs
│   ├── WearableApp ← Diseños de interfaz para la app wearable
│   └── WebApp      ← Diseños de interfaz para la aplicación web
├── NFRs            ← Non-Functional Requirements (Requerimientos No Funcionales)
├── UHs             ← User Histories (Historias de Usuario)
└── URs             ← Use Cases / Use Requirements
```
